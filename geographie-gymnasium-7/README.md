# Geographie 7 Gymnasium

A German-language course on Europe for Bavarian Gymnasium Grade 7. The 23
lessons follow the six learning areas in the [official LehrplanPLUS](https://www.lehrplanplus.bayern.de/fachlehrplan/gymnasium/7/geographie).
Learners compare maps and satellite imagery, explore seven models, and respond
to guided and transfer prompts. Each lesson needs a correct check at both levels and a completed workshop. The course bundles its visual assets and saves
progress and writing in the browser. Its 46 ZAM cards link to their lessons.

Run `npm ci` and `npm run dev` for a local server on port 5274.
Use `npm run package:zip` to build a standalone archive with Windows, macOS
and Linux launchers. The ZIP can be opened without a network connection.

See the [curriculum matrix and evidence](coverage.json), [approved legacy mapping](replaces-de-by.json)
and [map and image credits](src/data/NOTICE.md). The package is version 0.0
and awaits teacher review.

## For parents and teachers

The app keeps practice progress and free writing in the current browser
profile. Learners compare their own work with examples. When a device account
is shared, use “Lokalen Fortschritt zurücksetzen” on the learning path at the
end of the session to clear the package's progress and writing.
