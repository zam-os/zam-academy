Made with Natural Earth. Free vector and raster map data @ naturalearthdata.com. Public domain.

The base map uses the [Natural Earth v5.1.1 Admin 0 countries](https://github.com/nvkelso/natural-earth-vector/blob/v5.1.1/geojson/ne_110m_admin_0_countries.geojson), projected by `scripts/build-map-data.mjs`. The published geometry is intended for orientation and uses Natural Earth's small-scale boundary conventions. Thematic labels, routes and examples are Academy overlays.

The Rotterdam radar image [Earth from Space: Southwest Netherlands](https://www.esa.int/media/earth-from-space-southwest-netherlands-en-377990) contains modified Copernicus Sentinel data (2022–23), processed by ESA, distributed under [CC BY-SA 3.0 IGO](https://creativecommons.org/licenses/by-sa/3.0/igo/). The offline copy is resized and recompressed. The diagram below it is an independent Academy schematic.
